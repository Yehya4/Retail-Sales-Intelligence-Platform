# Données sources

Ce répertoire contient les fichiers CSV bruts du dataset **Brazilian E-Commerce Public Dataset by Olist**.

## Fichiers attendus

| Fichier | Description |
|---|---|
| `olist_orders_dataset.csv` | Commandes et statuts |
| `olist_order_items_dataset.csv` | Lignes de commande |
| `olist_customers_dataset.csv` | Clients et localisation |
| `olist_products_dataset.csv` | Produits et catégories |
| `olist_sellers_dataset.csv` | Vendeurs |
| `olist_order_payments_dataset.csv` | Paiements |
| `olist_order_reviews_dataset.csv` | Avis clients |
| `olist_geolocation_dataset.csv` | Données géographiques |
| `product_category_name_translation.csv` | Traductions des catégories |

## Téléchargement

1. Créer un compte sur [Kaggle](https://www.kaggle.com)
2. Accéder au dataset : https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
3. Télécharger l'archive ZIP et extraire les CSV dans ce répertoire

## Important

> ⚠️ Ces fichiers **ne sont pas versionnés** (voir `.gitignore`).  
> Chaque utilisateur doit les télécharger indépendamment depuis Kaggle.
